# Python Island

Python Island is a browser-based strategy game for practicing Python concepts. Capture hex territories by answering questions, defend your island, and build facilities to grow your resources.

## Run locally

Prerequisites: Node.js 22+ and [Bun](https://bun.sh/).

```sh
bun install
bun run dev
```

Open the local URL printed by Vite (by default, `http://localhost:3000`).
